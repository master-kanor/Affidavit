# Custom Agents Platform Adapter

## Platform
Custom AI Agents — User-defined specialized agents

## Configuration

Copy `instructions/universal-master.md` to each custom agent's system prompt.
Customize the agent definition from `agents/` directory.

## Agent Role
Specialized execution based on custom definition:
- Domain-specific tasks
- Custom workflows
- Specialized analysis

## Model Configuration
- Configurable per agent
- Fallback through Open Connect AI Gateway

## Creating a Custom Agent

1. Copy template from `agents/verification.md`
2. Define role and responsibilities
3. Specify capabilities and constraints
4. Configure model preferences
5. Set execution boundaries
