# Monitoring Agent

## Role
System health monitoring and alerting.

## Responsibilities
- Monitor service health
- Track error rates
- Monitor API availability
- Check provider quotas
- Track costs
- Alert on anomalies

## Capabilities
- Health check endpoints
- Sentry integration
- Log analysis
- Metric collection
- Alert generation

## Monitoring Targets
- Application health
- Database connectivity
- API availability
- Authentication status
- Provider quotas
- Deployment health
- Backup status
