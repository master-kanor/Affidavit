04 / FRONTEND RESPONSIBILITY MAP

Components separate review, editing, and source viewing.

Each component owns one bounded responsibility. The page can organize a documentary, but it cannot mutate the canonical affidavit through its editorial controls.

WORKSPACE
DOCUMENTARY WORKSPACE PAGE + HEADER
Loads the authorized aggregate, exposes case status and permissions, and coordinates view-only, editing, review, conflict, and export states.
01
REVIEW + NAVIGATION
CHAPTER LIST
Ordered chapters, selection state, keyboard reorder boundary, and count summaries.
CHAPTER CARD
Status, narration preview, item count, reviewer identity, and timestamp.
REVIEW DIALOG
Explicit submit, approve, reject, reopen, and archive actions with reason capture.
02
EDIT + COMPOSITION
EDITOR DRAWER
Editorial title, description, and narration only; never source affidavit wording.
ITEM GRID
Ordered resource cards with caption, notes, removal, and controlled reordering.
RESOURCE PICKER
Searches only visible, case-scoped sections, evidence, testimony, events, and links.
03
PROVENANCE + AUDIT
RELATIONSHIP PANEL
Displays source link, confidence, verification, and Accept / Modify / Reject decisions.
AUDIT TIMELINE
Shows actor, action, time, reason, and before/after summary from server records.
EXPORT REVIEW
Verifies approval readiness and shows the exact reproducible documentary snapshot.
INTEGRITY BOUNDARY
NARRATION, ORDER, CAPTIONS, AND EVIDENCE RELATIONSHIPS ARE EDITORIAL RECORDS. CANONICAL AFFIDAVIT TEXT LIVES IN A SEPARATE, READ-ONLY VERSIONED DOMAIN.
