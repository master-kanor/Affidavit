08 / CHAIN OF CUSTODY

Security and provenance at every layer.

Authority, evidence visibility, source preservation, and auditability are enforced by a sequence of independent controls — not by a client-side promise.

LAYER 01
ROLE-AWARE API CHECK
Owner/Admin mutations; Guest Reviewer remains view-only. Authority derives from the validated session.
LAYER 02
ROW-LEVEL SECURITY
Database policy filters every case, resource, and relationship to the principal’s authorized scope.
LAYER 03
SOURCE INTEGRITY
Documentary routes compose editorial records but cannot update affidavit text versions.
LAYER 04
AUDIT TRANSACTION
Each mutation writes actor, action, before/after values, request context, and optional recommendation link.
LAYER 05
CONTROLLED MEDIA
Only normalized, approved provider URLs may render. Missing external evidence links are never invented.
